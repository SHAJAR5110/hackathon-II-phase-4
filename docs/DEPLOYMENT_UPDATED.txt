KUBERNETES DEPLOYMENT - STEP BY STEP EXECUTION
==============================================

YOU HAVE DELETED DOCKER IMAGES - START FRESH!

STEP 1: Build Frontend Image (2-3 minutes)
==========================================

docker build -t todo-frontend:1.0 -f docker/frontend/Dockerfile .

Verify:
  docker images grep todo-frontend
  Shows: todo-frontend  1.0  IMAGE_ID  150MB

STEP 2: Build Backend Image (2-3 minutes)
========================================

docker build -t todo-backend:1.0 -f docker/backend/Dockerfile .

Verify:
  docker images grep todo-backend
  Shows: todo-backend  1.0  IMAGE_ID  600MB

STEP 3: Start Minikube (1-2 minutes)
===================================

minikube start --memory=4096 --cpus=4

Verify:
  minikube status
  kubectl get nodes

STEP 4: Load Images to Minikube (1 minute)
==========================================

minikube image load todo-frontend:1.0
minikube image load todo-backend:1.0

Verify:
  minikube image ls grep todo

STEP 5: Validate Helm Chart
===========================

helm lint helm/todo-chatbot/

Expected: 1 chart(s) linted, 0 chart(s) failed

STEP 6: Deploy with Helm (1-2 minutes)
======================================

helm install todo-chatbot helm/todo-chatbot/ \--set secrets.databaseUrl="" \--set secrets.betterAuthSecret=""

Verify:
  helm list
  Shows: todo-chatbot  default  1  deployed

STEP 7: Wait for Pods (2-3 minutes)
==================================




All should show:
  READY: 1/1
  STATUS: Running

Watch:
  kubectl get pods -w

Check services:
  kubectl get services

STEP 8: Access Application
==========================

Terminal 1:
  kubectl port-forward svc/frontend-svc 3000:3000

Terminal 2:
  kubectl port-forward svc/backend-svc 8000:8000

Terminal 3:
  curl http://localhost:8000/health
  Expected: {"status":"ok"}

Browser:
  http://localhost:3000
  Expected: App loads

STEP 9: Test Application
========================


1. Sign up
2. Login
3. Create task
4. View tasks
5. Mark complete
6. Delete task

If all work = SUCCESS!
