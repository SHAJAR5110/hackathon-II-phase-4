QUICK REFERENCE
===============

Commands:
  Docker: docker build, docker run, docker push
  K8s: kubectl apply, kubectl get, kubectl describe, kubectl logs
  Helm: helm install, helm upgrade, helm rollback
  Minikube: minikube start, minikube image load

Concepts:
  Docker Image: Blueprint (immutable)
  Docker Container: Running instance
  K8s Pod: Smallest unit (container wrapper)
  K8s Deployment: Manages pods (replicas)
  K8s Service: Load balancer & network
  Helm Chart: Template for K8s resources

Key Points:
  Docker = Containerization (consistency)
  K8s = Orchestration (auto-scaling, self-healing)
  Helm = Package manager (templating, versioning)
